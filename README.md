# RankTrack Lite

Google organic keyword rank checker. Enter your own SerpAPI key, website, keywords, country, optional city and device. Test the key before starting. Export results as CSV. No dependencies or saved keys.

Run `python app.py` locally and visit http://127.0.0.1:8765. On Render use Python runtime, build command `python -m py_compile app.py`, start command `python app.py`, and free plan. The server reads PORT and exposes /health. Public deployments are for personal use; add authentication and rate limiting for wider distribution.
